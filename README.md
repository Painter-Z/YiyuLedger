# 一语账

一语账是一款支持原生鸿蒙与安卓的 AI 语音记账应用。按住语音键说出消费或收入，即可自动识别名称、金额、分类和日期，支持一句记录多笔、手动及文字输入、账单搜索与编辑、周／月／年收支图表、月预算提醒，以及 CSV 导出和 JSON 备份恢复。填写自己的百炼 API Key 后即可联网识别，账本保存在本地。
