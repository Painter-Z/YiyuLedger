# 0.4.0 确认页、适配与统一删除

本页保留0.4.0适配和删除规则记录。当前鸿蒙0.5.0 / 安卓0.6.0新增左滑删除与月预算，见[本轮说明](SWIPE-AND-MONTHLY-BUDGET.md)；当前账单数量以最新验证记录为准。

更新：2026-10-11。实际设备为 HUAWEI Pura 80 Pro / LMR-AL00 / HarmonyOS 6.1.1 / API 24。支持范围由系统版本、窗口和能力决定，不为每个手机型号生成独立界面。

## 确认流程

1. AI 返回的有效分类保持选中；本地按描述关键词、自定义分类名称及历史更正提供至多两个替代项，推荐不表示模型置信概率。
2. “更多”与实际的“其他”分类分开，展开完整分类网格；选中任一分类后收起。
3. 网格包含“自定义”，按收支类型建立1至12字名称。支出与退款共享分类，收入、转账和往来各自区分。已使用分类不能移除；未使用的自定义分类可长按移除。
4. 名称、日期、备注在中间滚动区；保存按钮是独立底栏。展开分类、长原话、出现校验提示和弹出键盘都不要求滚到内容末尾才能保存。创建分类时底栏临时改为“创建并选用”。
5. 识别原话默认最多两行，点按可展开；多笔仍逐笔确认。

## 适配规则与验证边界

| 场景 | 实现与验证 |
| --- | --- |
| 常规、窄屏窗口 | 按可用窗口宽度设置16/24vp边距；原生窗口尺寸监听并在前台重新读取像素/vp关系，适应显示缩放和窗口变化 |
| 大字体 | 显式跟随系统，最大比例3.2；按钮、输入框随字号增高；推荐数量减少，全分类网格2至5列；长名称截断处保留完整可访问标签 |
| 大金额 | 首页及统计金额按可用宽度适应；编辑金额根据长度和字号计算尺寸，避免遮盖邻近内容 |
| 宽屏、横屏、折叠窗口 | 主内容最大720vp、确认面板最大600vp居中；尺寸变化重新布局；跟随系统自动旋转开关。尚未完成其他实体机型、折叠屏和横屏真机验证 |
| 状态栏、挖孔、底部手势区 | 沿用系统非全屏安全区布局，不扩展交互内容到系统区域 |
| 键盘 | 使用 KeyboardAvoidMode.RESIZE 压缩页面，中间 Scroll 占剩余空间；底栏跟随窗口上移到键盘上方 |
| 页面切换 | 切换主页、账单、统计和设置时回到相应页面顶部，不继承上一页的滚动位置 |

真机实测了标准字体/默认显示、特大字体/默认显示、特大字体/大显示缩放，包含键盘、完整分类和最大有效金额输入。测试后恢复了原先“标准”字体、“标准”粗细、“默认”显示缩放。自动检查覆盖280/320/360/390/412/600/840/1280vp与1/1.15/1.3/1.75/2/3.2字体比例的48个组合，验证宽度上限、推荐数量及触控尺寸；这些计算检查不能替代对应设备的实际渲染测试。

最低兼容及目标仍为 HarmonyOS 5 / API 12。当前签名包绑定现有真机；适配更多型号与获取其他设备的安装资格是两项独立工作。其他系统版本及手机、折叠屏需要补充测试，安卓需要另建 APK。

## 删除规则

- 新的删除操作带确认弹窗，在同一数据库事务中移除账目、解除其他独立账目的失效引用，并清理已确认提案副本。关联退款等独立交易继续保留其金额和方向。
- 不再保留回收站与短时撤销副本。升级自动清理旧版 `deletedAt > 0` 的行，当前有效账单不改写。
- 每次确认语音账单都推进稳定编号的 `savedCount`，同时裁去缓存中已确认的提案与整段原文，用 `resultOffset` 记录剩余数组的起点。部分确认后重启仍继续下一笔，不重新生成已确认账单。
- 尚未确认的其他提案继续保留，失败录音仍按24小时策略处理。录音路径只接受本应用私有目录中生成的文件名。
- 新 JSON/CSV 导出只包含当前账单；JSON v2同时保存自定义分类定义，支持旧版v1导入。旧备份中已标记删除的行不导入；已导出为有效账单的独立文件保留，可由用户主动恢复。
- API Key 属于单独的系统加密资产，删除账单和迁移不会移除密钥。账本文件不包含密钥。

验证包含40项客户端测试：金额/统计、分类与备份、缓存进度、响应式约束，以及直接运行原生存储源码的 SQLite 事务测试。真机验证了创建、保存、删除和分类移除，并核对原有效账单内容未变。本轮临时测试记录没有保留。
