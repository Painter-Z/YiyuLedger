# 一语账手机使用说明

当前鸿蒙手机已安装0.7.0，已保存的个人密钥和有效账单继续保留。电脑可以关闭，USB可以拔掉。

## 语音记一笔

1. 打开“一语账”，手机保持 Wi-Fi 或移动数据联网。
2. 按住首页语音键，例如说：“我中午吃了辣椒炒肉盖饭，花了15元。”
3. 松开，核对待确认账单里的消费名称、金额、分类和日期，需要时直接修改。
4. 点击底部常驻的“确认保存”。一次说了多笔，逐笔确认保存。

可自然说“十一块八毛九”“两块五”等金额。多笔确认时显示“第X笔 / 共Y笔”，上方原话只展示当前这笔对应的片段；请核对各笔名称与金额。异常结果会自动复核一次，仍不确定的字段留空并提示补填。不会把两笔同名消费自动合并。见[鸿蒙0.7.0说明](HARMONY-0.7.0-RECOGNITION.md)。

分类默认显示已选项及最多两项推荐；点“更多”展开全部分类。选择后自动收起。点展开列表的“自定义”，填写1至12字名称，再点底部“创建并选用”。新分类也参与后续智能识别、搜索、统计和备份。小屏或大字体下推荐数量会减少，全部分类始终可从“更多”找到。长按未使用的自定义分类可移除，已有账单的分类受到保护。

按住后上滑再松手可取消。首次使用麦克风需要授权，授权后重新按住开始。每次录音最多30秒。

## 断网或识别失败

手动记账、查看账单和周/月/年统计可离线使用。语音和文字智能识别需要联网；失败后首页会出现“未完成记录”，恢复联网后点进去重试。失败录音暂存24小时，到期后在下次打开或回到应用时自动清理。

不是记账内容或没有听清时直接删除录音。识别成功后也删除录音，只保留待确认账单；关闭确认页后可以从首页继续，未确认的提案不会直接计入统计。

## 密钥和账本

新安装用户打开“设置 → 添加 API Key”，填写自己的阿里云百炼密钥，点击“保存并启用”即可。应用自动验证后加密保存，不需要选择连接方式、填写服务地址或单独测试。

当前密钥已经保存，无需每次填写；更换时点击“更换 API Key”，输入新的个人密钥并保存启用。原密钥不会回显，验证失败不会替换已有密钥。识别用量计入自己的百炼账号。

账本保存在手机本地。在设置中导出完整JSON备份可恢复账单、自定义分类和月预算，支持与安卓0.6.2互相迁移；CSV适合查看和汇总。卸载或更换设备前先备份并处理未确认录音；备份不包含密钥和录音草稿，新设备需要重新配置个人密钥。

## 查看与搜索账单

默认展示今天、昨天、前天，按账单发生日期分组；日期右侧显示当天全部支出，收入、退款、转账及往来不计入这个金额。搜索和类型筛选不会把全天支出变成部分金额。更早的账单完整保留。

搜索栏左侧日历可选择某一天，弹窗在屏幕中间，顶部居中只显示该日期的星期。选定后保留当前收支类型及关键词，只看当天；在当日账单最下方点击深绿色“返回”，清除关键词和日期、分类条件，保留收支类型并恢复近三天。没有账单的日期也显示“返回”。

没有指定日期时输入关键词搜索全部历史；选定某一天或从统计进入时，只在当前日期范围内搜索。输入即时筛选，右侧搜索按钮及键盘搜索键收起键盘并显示结果。手动记账入口位于“记账”页。完整规则见[日期与搜索说明](HARMONY-LEDGER-BROWSING.md)。

## 删除账单

在“账单”页向左滑某一笔，点击右侧红色“删除”，再确认即可；也可进入编辑页删除。账单从数据库、统计及预算已用金额中移除，相关已确认语音缓存同步清理；同段语音中尚未确认的其他账单保留。应用内不设回收站。新导出文件仅包含当前账单，之前导出的独立文件保留；导入旧备份时不会恢复其中标记为已删除的记录。

## 月预算

在“统计”页“收支趋势”上方点击预算卡片的“设置”，输入每月消费额度并保存。圆环中心显示剩余可用金额；超支后显示红色超支金额，红色逐渐覆盖已用进度。下方同时显示预算与已消费，超过两倍额度时圆环保持红色。

后续月份自动沿用额度，直到再次调整；可从指定月份关闭。月视图跟随所选月份，周和年视图显示明确日期的本月预算。当月退款抵减消费，收入、转账和往来不占预算。设置和查看都可离线完成。
