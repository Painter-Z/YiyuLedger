# 一语账配色与布局

更新日期：2026-10-14。当前安卓0.6.1、鸿蒙0.6.1；统一主题最初用于安卓0.5.1、鸿蒙0.4.1。鸿蒙0.6.1继续沿用0.5.2底色，日期弹窗及星期标题居中，账单末尾“返回”沿用“确认保存”的森林绿背景、浅色文字、16vp圆角和至少50vp高度。

两端使用同一份`shared/theme.json`管理配色：`colors`为基础配色，`platformOverrides`记录两端的底色调整。安卓0.6.1此前同步鸿蒙0.5.2的三种底色。`tools/sync-theme.py`生成Kotlin和ArkTS常量，`--check`核对两端各自的有效配色；本轮不改动两端色值及安卓源码。

下表为基础配色；当前两端的三个底色覆盖见下方0.5.2及0.6.1说明。

| 用途 | 颜色 | 使用位置 |
| --- | --- | --- |
| 主色 | `#234236` 深绿 | 首页的本月收支卡片、保存按钮、选中项、麦克风圆底 |
| 页面 | `#F7F8F3` 浅米白 | 首页、账单、统计、表单的页面底色 |
| 卡片 | `#FEFEFB` 暖白 | 收支统计、预算及设置卡片、底部导航 |
| 语音与推荐 | `#E1EBD3` 浅绿 | 语音按钮、选中分类 |
| 输入区域 | `#EFF2EA` 灰绿 | 金额、名称、日期和未选分类 |
| 正文 / 辅助文字 | `#30483C` / `#64735F` | 提高文字辨识度，区分信息层级 |
| 支出 / 收入 / 退款 | `#476B53` / `#906B40` / `#507580` | 图表与金额方向；仍保留文字标签 |
| 错误 / 取消 | `#AD594C` | 错误提示和取消录音状态 |

安卓首页去掉此前的渐变，语音按钮改为与鸿蒙一致的浅绿底、深绿麦克风。鸿蒙原先偏淡的辅助文字同步加深。两端的界面组件遵循各自原生交互；屏幕显示模式、色温和系统字体仍会影响实际观感。

安卓同时补齐 Material 弹窗容器、提示条和图表文字的颜色，避免沿用默认主题中的淡紫色或旧版灰色。

当前采用固定浅色主题，安卓同时设置深色状态栏图标并关闭系统强制反色，防止切换系统深色模式后出现白图标或意外改色。完整深色主题可作为后续独立功能。

安卓确认页保留固定底部保存按钮，正文单独滚动；键盘出现时缩短正文，而不是让保存按钮被键盘覆盖。窄屏时减少推荐分类数量，大字体时日期换成两行。金额根据空间缩放，长账单名称和大金额在需要时上下排列；图表根据标签实际宽度减少横轴标签。

横屏键盘占据大部分屏幕时，确认页暂时收起标题，将关闭按钮放到保存栏旁，给正在输入的内容留出空间。键盘收起后自动恢复标题；“确认保存”保留至少 48dp 的点击高度。

首页结余在空间不足时上下排列；鸿蒙0.5.1的统计收支按用户偏好恢复左右双列，长金额通过缩小字号保持完整。安卓0.6.1同步“净支出 / 收入”双列，并检查大字体和长金额字符的实际显示范围。

## 鸿蒙0.5.1颜色核查

对照0.4.0与0.5.1源代码，早期页面底色为`#F5F5EF`，统一主题后为`#F7F8F3`；周/月/年切换区域由`#E9EEE0`调整为`#EFF2EA`。页面与筛选底色均比早期更浅。统计卡片由`#FEFEFA`变为`#FEFEFB`，仅蓝色通道增加1，卡片自身差异很小。预算自0.5.0加入起即使用`#FEFEFB`，与统计卡片相同。0.5.0→0.5.1没有改动上述色值。

鸿蒙三个页面的根容器均为不透明纯色，没有渐变、背景图片或背景模糊声明。对旧、新真机截图左侧页面空白处的6个高度（400、800、1200、1600、2000、2400px）采样，同一版本从上到下颜色一致：旧截图为`#F5F5F0`，0.5.0与0.5.1为`#F7F8F3`。旧截图与源色的蓝色通道相差1，不影响纯色结论。采样覆盖记账、账单、统计的现有截图；不据此诊断手机物理屏幕的显示效果。

布局、卡片面积、浅绿圆环及文字对比变化可能影响对明暗的判断，这是视觉分析，无法仅凭源码确认用户在屏幕上感知差异的全部原因。以上为0.5.1核查时的记录，当时没有调整配色；之后用户授权恢复早期底色，结果见下文。

## 鸿蒙0.5.2恢复暖灰底色

| 用途 | 鸿蒙0.5.2 | 安卓0.6.0历史值 |
| --- | --- | --- |
| 页面 | `#F5F5EF` 暖灰米色 | `#F7F8F3` |
| 卡片 | `#FEFEFA` 暖白 | `#FEFEFB` |
| 筛选与输入区域 | `#E9EEE0` 浅绿 | `#EFF2EA` |

统计与预算卡片使用同一种暖白底色；所有页面继续使用不透明纯色背景。保留现有文字辨识度、双列收支、直角删除按钮、16vp间距和标准22vp圆环。主题平台覆盖使之后运行生成脚本时也不会意外把鸿蒙颜色恢复成安卓的基础值。

已覆盖安装并检查记账、账单、统计三个页面。截图页面空白处的6个高度均为`#F5F5F0`，与0.4.0旧截图一致；统计和预算卡片均为`#FEFEFA`，周/月/年切换区域为`#E9EEE0`。账单汇总和未设置预算状态保持原样，未保存或删除测试数据。

截图及设备测试结果见[验证记录](VALIDATION.md)与[安卓兼容测试](ANDROID-COMPATIBILITY.md)。鸿蒙0.5.2已覆盖安装到Pura80Pro，最新配色截图见对应验证记录。

## 安卓0.6.1同步

安卓采用与鸿蒙0.5.2一致的页面 `#F5F5EF`、卡片 `#FEFEFA`、输入与筛选 `#E9EEE0`。统计和预算卡片均使用暖白背景及细边框；周/月/年区域使用浅绿底与暖白选中项。删除按钮采用直角红色矩形及16dp留白，圆环标准线宽22dp，中心文字按内径及系统字体缩放限制范围。实际像素与交互测试结果见[安卓0.6.1](ANDROID-0.6.1.md)。
