# 安卓 0.6.2：同步鸿蒙账单日期与搜索

安卓 0.6.2 / code9，参照本机最新鸿蒙 0.6.1 / code1000010。只更新安卓，鸿蒙代码和已交付 HAP 保持原样。

## 功能与规则

- 默认显示今天、昨天、前天三个自然日，按发生日期倒序。较早和未来账单继续保存在完整账本中；统计、预算、导出和备份使用完整账本。
- 日期右侧显示当天全部有效人民币支出，收入、退款、转账和往来不计入此金额。类型、关键词、分类和每批 80 笔的展示限制不改变全天合计；保存、修改、删除后由同一账本重新计算。
- 搜索栏为左侧日历、中间输入、右侧搜索按钮，支持清空文字。输入即时筛选；搜索按钮或键盘搜索键收起键盘。未指定日期时搜索全部历史，清空关键词恢复近三天；指定日、月或统计范围时在该范围内搜索。
- 日历弹窗在安全显示区域水平、垂直居中。顶部只显示居中的“星期X”，滚轮变化时更新；两侧留出相同空间，右侧关闭按钮仅显示叉号，保持 44dp 点击区域。底部并排放“取消”和“确定”。
- 年/月/日固定为中文顺序，采用系统 NumberPicker 滚轮，避免不同系统语言或厂商 DatePicker 改变顺序。支持 1900–2199 年，并按所选年月校正有效天数；选定日期前不会改变账单范围。
- 确定日历日期替换原日期范围和统计分类条件，保留关键词及收支类型。取消及叉号关闭保留原查询条件。
- 结果全部加载后，在最后一笔后显示森林绿“返回”按钮；无结果时同样提供。点击清空搜索、日期、范围和统计分类，保留收支类型，恢复近三天。默认近三天不显示。
- 从统计趋势、分类或合计跳转时保留相应日、月、周期和分类，支持继续切换收支类型。切换标签页保留查询状态；日期查询在旋转重建后仍保留。
- 应用回到前台、切回账单页、本地午夜及系统时钟/时区变更时更新自然日。午夜定时任务只在前台运行。
- 首页入口名称更新为“查看账单”。原有语音、手动确认、分类、滑动删除和预算功能继续使用。
- 横屏搜索时收紧顶部标题栏，为键盘上方的输入框、搜索和日历按钮留出完整空间；退出键盘后恢复通常布局。

具体鸿蒙规则见 [日期与搜索](HARMONY-LEDGER-BROWSING.md)。默认字号为本轮适配重点，大字体不列入此次专项。

## 验证方法

`tools/generate-browse-fixtures.mjs` 从鸿蒙 LedgerBrowse 生成 20 组纯合成样例；安卓 Kotlin 对照相同日期范围、匹配编号、每天金额、空日期和标题。共 23 项 Kotlin 单元测试、56 项现有鸿蒙及共享测试通过；Lint 0 错误，4 条现有依赖升级提示。

界面专项验证完整搜索、日期滚动及星期更新、取消、空日、返回、删除后金额刷新、统计跳转、82 笔跨批加载、旋转重建和合法备份编号与分组标识的隔离；在截图像素上检查弹窗与星期字形中心、关闭按钮背景、点击区域和返回按钮颜色。字号均为 100%。

| --- | --- | --- | --- |
| Android 15 / API35 | 通过 | 通过 | 通过 |
| Android 16 / API36 | 通过 | 通过 | 通过 |
| Android 17 / API37 | 通过 | 本轮未测 | 本轮未测 |

七种配置共十项完整界面流程、72 张截图及对应布局。结果位于 `artifacts/android-0.6.2-browse-ui/api*/results.json`，各报告记录实际安装 APK 的同一 SHA-256。三个系统另外各15项基础及预算回归全部通过。Android 17 使用本机稳定 Emulator 36.6.11 直接 QEMU 路径启动；不是小米澎湃系统镜像。测试环境手势区域和键盘动画采样时序的排查见[验证记录](ANDROID-VALIDATION.md)。

复现前先启动对应 API 的开发模拟器，再执行：

```powershell
.\tools\build-android.ps1 -Mode Check
.\tools\build-android.ps1 -Mode ConnectedTest -TestClass 'com.yiyu.ledger.KeyStoreTest,com.yiyu.ledger.LedgerUiTest,com.yiyu.ledger.RepositoryTest,com.yiyu.ledger.VoiceGestureTest' -ReportName android-0.6.2-api36-baseline.log
python tools\run-ledger-browse-ui-check.py --api 36
```

此脚本依赖 Pillow，所有合成账单仅在开发模拟器创建、编辑、删除。不能运行到真实手机；测试期间没有云端识别请求，没有修改用户账本或密钥。真实小米定制系统仍需由朋友日常使用确认。

## 安装

个人测试 APK 为 `artifacts/YiyuLedger-0.6.2-android-debug.apk`，20,380,282 字节，SHA-256：`9ee6c466255ad2b4f5f83f5a1421ad3abbfd519584d5c79415cc03456cd697ec`。应用 ID 和签名沿用 0.6.1，直接覆盖安装，保留账本、预算及加密密钥；不要先卸载。最低 Android 8.0，不依赖 Google Play 服务。APK 签名、ZIP 完整性、16KB ZIP 与原生库对齐检查通过。

交付清单、摘要和通过项目见 `artifacts/release-android-0.6.2.json`。此前个别小米输入法动画偏慢反馈继续作为待观察项，本次没有修改金额确认页的键盘路径。
