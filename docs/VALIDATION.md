### 云端与自动检查

- 真实 Fun-ASR-Realtime 与 Qwen 均已调用成功。密钥只保存在本机被忽略的 `backend/.env`；手机使用独立连接口令，源码包去除环境文件、口令与本地签名配置。
- HTTP `/api/parse` 实测：“昨天坐地铁，花了八块五毛”→ 交通8.50元/昨天；“午饭15元，不对是13元，今天工资到账8000元”→ 餐饮13元及工资收入8000元；自己账户转账1000元与退款200元分别提取为转账和退款。
- 使用 Windows 本地语音合成生成16kHz/单声道/16bit的4.79秒普通话录音，内容为盖饭15元。真实 HTTP `/api/transcribe` 返回正确菜名、餐饮和15元；实际 WebSocket `/api/voice` 收到10次中间文本并返回正确最终账单。这项为合成语音测试，与上面的真人手机录音区分。
- 领域逻辑：`node --test tests/*.test.mjs`，16项通过，覆盖货币精度、日历、跨年周、跨月退款、统计排除、备份完整性、CSV转义和同金额独立账单。
- 服务接口：`python -m pytest backend/tests -q`，38项通过，使用模拟提供方；覆盖金额证据、口误、不完整内容、日期、多笔结果、鉴权、格式/时长/大小限制、实时协议和ASR句子去重。真实云端验证单独列在前面。
- `node tools/check-project.mjs` 已通过工程入口、权限、资源及引用完整性检查。浏览器预览已验证手动保存/刷新持久化、删除撤销、统计筛选与360×800窄屏布局。
- `tools/start-usb-service.ps1` 在已连接手机和已有服务的环境中运行通过，识别现有反向通道并复用服务，无需重新填写手机连接信息。冷启动分支调用已有服务启动脚本；本次未为验证该分支中断用户服务。

服务自动测试有1条上游 Starlette/httpx 弃用提示。原生编译存在可能抛出异常、音频设备能力及旧 UI API 弃用等提醒，构建无错误；没有关闭编译检查。
