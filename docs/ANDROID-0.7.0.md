# 安卓0.7.0：口语金额与多笔账单对应

2026-10-18，版本0.7.0 / code11。将已交付鸿蒙0.7.0的识别优化同步到安卓，鸿蒙源码及安装包保持原样。

## 记账行为

- “十一块八毛九”“11块8毛9”“十一元八角九”按11.89元解析；“两块五”为2.50元，“八毛九”为0.89元。含糊、省略或无法独立核实的金额保持待填写。
- 每笔提案引用自己的连续原话、名称和金额。模型复制了上一笔名称时，按本笔引用校正；引用也错配时留空并复核，避免带着错误名称继续保存。
- 例如“今天我吃了保障餐，花了八块。又喝了一碗粥，花了两块五”，分别确认“保障餐8.00元”和“粥2.50元”。真实的同名、同价交易仍保留多笔。
- 模型返回顺序混乱时按原话顺序恢复；汇总、找零不重复记账，合并付款保留一笔，不推测单项价格。
- 正常结果仅调用一次Qwen，异常最多复核一次。复核失败、无改善或丢失原有提案时保留原始待确认内容。用户取消操作仍正常取消，不会被复核兜底吞掉。
- 确认页显示当前这笔原话，可点开查看完整内容；多笔时显示“第X笔 / 共Y笔”，保存后进入下一笔。分类推荐使用当前片段，底部保存区继续固定。

## 数据与更新

应用ID及调试签名沿用0.6.3，可直接覆盖安装，保留账本、预算和系统加密密钥；不要先卸载。旧版未完成提案缺少新字段时继续读取，无需重新识别或重新输入密钥。

账本数据库及CSV / JSON v3备份格式不变。原话只存于待确认提案，保存一笔后裁剪该笔提案与原话，保留剩余未确认内容。没有添加模型训练、会员、账号或新服务模式。

模型仍为`fun-asr-realtime`与`qwen-plus`。本次强化转写后的提取和核验，实际口音、噪音及同音词仍需通过朋友试用收集样例。
