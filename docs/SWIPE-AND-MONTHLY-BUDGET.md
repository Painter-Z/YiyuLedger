# 左滑删除与月预算

2026-10-14，当前鸿蒙0.6.1 / code1000010，安卓0.6.1 / code8。左滑删除和预算两端均已实现；安卓0.6.1此前对齐鸿蒙0.5.2的直角删除按钮、16dp留白、双列净支出/收入、22dp圆环与暖灰配色。鸿蒙支持近三天账单和日期搜索，本轮调整居中日历与账单末尾返回入口，见[日期与搜索](HARMONY-LEDGER-BROWSING.md)，安卓保持原样。以下保留原始预算功能规则和安卓0.6.0首次验证记录。

鸿蒙0.5.1将删除操作改为直角长方形，与金额预留16vp空白；收支统计恢复净支出、收入左右双列，保留长金额缩小字号；预算底环、消费及超支弧统一加粗，标准208vp圆环的线宽为22vp，小尺寸按比例收窄，文字区域随内径调整。

鸿蒙0.5.2保留上述布局，按用户偏好恢复0.4.0风格的暖灰页面底色与浅绿筛选区域。统计和预算卡片统一暖白底色；页面保持纯色。具体色值及核查见[配色说明](UI-THEME.md)。

## 日常使用

- 在“账单”页，把手指放在某一笔账单内部向左滑，右侧出现红色“删除”。点击后确认即可删除，无需进入编辑页。滑动本身不删除；取消弹窗保留账单。竖向浏览、切换页面或筛选时收起删除按钮。
- 在“统计”页，“收支趋势”上方有月预算卡片，点击“设置”填写每月消费额度。支持两位小数，不能填写0或负数；不需要联网。
- 月视图显示所选月份的额度和消费；周、年视图显示明确标注年月的本月预算。预算总是按自然月计算，不随周或年累计。
- 设置后，后续月份沿用最近一次额度，直到再次调整；已单独设置过的月份保留自己的额度。可选择“从该月起关闭预算”，重新设置后恢复。
- 测试结束不替用户预设额度，首次使用可自行设置。

## 数字与圆环

圆环中心优先显示可用于决策的金额：未超支时为“剩余可用”，达到额度时为“额度已用完 / ¥0.00”，超支后为红色“已超支”及超出的金额。下方显示“每月预算”和“已消费”，中心同时显示使用百分比，避免只凭颜色判断。

| 消费进度 | 圆环与文字 |
| --- | --- |
| 未设置 | 浅绿底环，提示设置；仍显示当月已消费 |
| 0–100% | 深绿沿底环逐步填充 |
| 100% | 深绿满环，剩余额度0 |
| 100–200% | 红色从顶端沿第二圈覆盖深绿，文字显示实际超支金额 |
| ≥200% | 满环保持红色，超支金额和百分比继续反映实际消费 |

预算消费为 `max(0, 当月支出 − 当月退款)`；退款按退款发生月份抵减，不倒改以前的月份。收入、转账、借还本金和已删除账单不占预算。超支提醒发生在应用内，没有另行加入推送通知或后台监控。

## 数据与恢复

预算金额使用整数人民币分。设置按月份保存，本机重启或同签名覆盖升级后保留；删除账单只更新已消费和剩余额度，不删除用户设置的额度。

完整JSON备份升级为v3，包含`monthlyBudgets`；两端继续读取v1/v2备份。导入先校验账单、分类和预算，然后事务合并。相同月份的本机显式设置优先，避免旧备份覆盖后来调整；任何非法字段或数据库写入失败均回滚。CSV保持逐笔账单格式。

## 实现与验证

鸿蒙使用ArkUI ListItem的右侧滑动操作，安卓使用Compose AnchoredDraggable，仅展开按钮，不因完整滑动自动删除。两端复用已有实际删除流程，统计、排行和预算均从当前有效账单计算。

0.6.0首次验证包括：共享的9组预算样例（恰好达到、超支1分钱、超过两倍及退款超额），48项鸿蒙领域/存储测试，15项Kotlin单元测试，Android16模拟器14项设备测试。新增Room v1→v2迁移、重启持久化、备份事务回滚、取消删除和实际删除后的预算刷新检查。当时的APK在320×720dp窄屏、360×800dp及200%大字体两组专项检查均通过，包含键盘显示时保存按钮可见；历史记录与APK摘要见`artifacts/android-budget-ui/results.json`。

鸿蒙Pura80Pro / 系统6.1.1 / API24已覆盖安装。实际验证预算20元与50元、键盘上方固定保存按钮、左滑展开、取消删除、竖向滚动收起、临时0.01元账单删除后消费27.51→27.50元与超支7.51→7.50元。最终逐项核对原有5笔账单内容完全一致，临时账单已移除，测试额度已关闭，结果见`artifacts/validation-0.5.0.json`。

Android APK已生成；本轮未连接安卓真机，模拟器结果不能替代朋友不同设备的实测。鸿蒙调试HAP仍受签名设备范围限制。
