# 鸿蒙账单日期与搜索

2026-10-14，鸿蒙0.6.1 / code1000010。鸿蒙交付时安卓0.6.1保持原样，随后安卓0.6.2同步这些规则，见[安卓更新](ANDROID-0.6.2.md)。

## 页面规则

- 默认按账单发生日期展示今天、昨天、前天三个自然日，日期倒序。不是最近有记录的三个日期；未来账单和更早账单不进入默认列表。历史数据继续完整保存。
- 日期右侧显示“支出：XX.XX元”，使用当天全部有效人民币支出之和。收入、退款、转账和往来不计入；与统计中的“净支出”区分。搜索、类型、分类和分批展示都不改变全天支出。账单编辑或删除后重新计算。
- 今天没有匹配记录时仍显示当天日期与支出，并提示没有相应账单。其他没有匹配记录的日期不占用空白分组；指定某一天时，即使无记录也保留该日标题与0元或当天实际总支出。
- 搜索栏左侧为日历，中间为输入框，右侧为搜索按钮。输入即时筛选；右侧按钮和键盘搜索键收起键盘并展示结果。输入框支持清空文字。
- 日历使用鸿蒙系统日期滚轮，可跨月、跨年选择日期。弹窗居中显示；顶部居中只显示所选日期对应的“星期X”，随滚轮实时更新，不重复显示年月日。右侧关闭入口只显示叉号，无圆形底色，保留44vp点击区域，不挤偏标题。确认后替换之前的日期范围及统计分类条件，保留当前关键词和收支类型；取消不改变筛选。
- 全部、支出、收入、退款、转账、往来继续独立筛选。日期只决定查看哪一天，不强制切换为支出。
- 没有明确日期范围时，输入关键词搜索全部历史，显示“全部日期 · 搜索结果”；清空文字恢复近三天。选定某一天、月份或统计范围后，搜索仅在该范围内进行。
- 指定日期、统计范围或全历史搜索时，在当前结果全部加载后的账单末尾显示深绿色“返回”按钮，与“确认保存”颜色、圆角和高度一致。没有匹配账单时也保留此入口。点击后清空关键词、日期范围和统计分类条件，保留当前收支类型，回到今天起的三天窗口。默认近三天不显示该按钮。
- 从统计趋势和分类排行进入时保留所点击的日、月或统计周期，不受默认三天限制。首页入口改为“查看账单”。
- 切回账单页、应用回到前台及持续使用跨过本地午夜时更新日期窗口。

## 列表与数据

`LedgerBrowse.ts`集中计算日期范围、匹配账单和全天支出。查询变化时计算一次，日期标题和各行复用结果，避免每个日期重复遍历和排序完整账本。列表首批展示80笔，滚动到底部或点击继续加载后每批增加80笔；合计金额始终包含完整当天支出。

本次不改变数据库结构、备份格式、完整账本、预算和统计的数据范围。应用仍在现有刷新流程中读取完整本地账本用于其他功能；80笔分批控制的是列表渲染，不是数据库分页。界面继续使用0.5.2的暖灰配色、直角删除按钮及加粗预算圆环。
