# 首次真机验收

当前鸿蒙0.5.0已覆盖安装到Pura80Pro（LMR-AL00 / 系统6.1.1 / API24），原有有效账单已核对保留。本轮验证左滑、取消与实际删除、预算设置及刷新、重启保留、键盘上方保存。此前已验证折叠分类、自定义分类、特大字体、大显示缩放、上滑取消及移动数据独立语音识别。历史结果见`VALIDATION.md`；下表为完整验收范围，其他项目仍需逐项执行。

| 项目 | 操作与预期 |
| --- | --- |
| 构建 | SDK编译无错误；调试签名成功；HAP安装并打开；记录设备型号/系统/API |
| 空账本 | 首次打开金额为0，无示例消费；三个主要入口清晰，系统栏和安全区域不遮挡 |
| 手动录入 | 餐饮15.01元保存；重启后保留；负数/0/多于两位小数不可保存 |
| 编辑与删除 | 修改金额与分类后汇总更新；删除需确认，实际移除数据库记录；列表、统计、识别副本同步清理；独立账单不误删 |
| 左滑删除 | 左滑只展开红色按钮，不自动删除；取消保留；竖向滚动或切换筛选收起；删除只影响所选账单 |
| 月预算 | 自定义正额度、重启保留、自然月累计与向后沿用；退款抵减；恰好用完和超支金额正确，超过两倍保持红色；删除账单立即刷新 |
| 分类折叠 | 自动选中最可能分类，显示最多两个备选；更多与实际“其他”分类可区分；展开后能改选全部分类 |
| 自定义分类 | 创建后选中；同组重复名拒绝；语音/文字解析、列表、统计及导出显示新名称；使用中的分类不可移除 |
| 权限首次 | 拒绝麦克风仍可手动记账；授权时松手不会继续录音，重新按住才能开始 |
| 基本语音 | “中午吃了辣椒炒肉盖饭，花了15元”→ 餐饮/菜名/15.00/中午；保存前账本无变化 |
| 独立联网 | 电脑识别服务关闭，USB拔掉、Wi-Fi关闭，移动数据下生成正确待确认账单（用户已确认通过）；日常使用无需电脑 |
| 个人密钥 | 只需添加Key并保存启用；自动验证后加密保存；已保存密钥不回显，格式/网络失败不覆盖旧密钥；移除后原账本保留 |
| 中文金额 | “地铁八块五毛”“买菜二十三元六角”金额核对正确，菜名/分类可改 |
| 多笔确认 | “盖饭15元，打车22元”；保存第一笔关闭；从首页未完成记录继续第二笔，无重复第一笔；删除已保存第一笔不删除独立的第二笔提案 |
| 口误 | “午餐15元，不对是13元”，结果必须核对13元；如不符手动改正 |
| 不完整 | “吃了个午饭”金额为空且提示补填；不能猜测金额或自动保存 |
| 非记账内容 | 闲聊、静音返回无提案，删除录音和临时记录；首页不出现无用的未完成入口 |
| 录音最小保留 | 成功提取后删录音，仅保留待确认账单；失败录音24小时后在下次打开/回前台清理；不能误删未确认账单 |
| 日期 | 昨天/前天落在正确日期；跨月月底、跨年周与闰年2月正确；无日期用录音日期 |
| 特殊类型 | 工资是收入；退款单列；转账到自己银行卡、借钱、还本金不增加收支 |
| 取消与时限 | 按住上滑松手取消，无账目；短按提示过短；达到30秒自动停止，麦克风指示消失 |
| 网络失败 | 关闭Wi-Fi和移动数据，识别失败后暂存录音；恢复手机联网后从未完成记录重试 |
| 后台打断 | 录音时切后台、锁屏、来电停止采集；回前台有草稿或明确状态，无持续占用麦克风 |
| 统计 | 周从星期一开始；周/月/年切换及上期下期金额正确；图表/分类点击明细对应实际范围 |
| 退款跨月 | 上月消费，本月退款；上月支出不变，本月退款和净支出变化 |
| 导出恢复 | CSV中文正常；JSON v3保留当前有效账单、自定义分类和预算；重复导入不重复，同月本机设置优先；兼容v1/v2，忽略删除记录；损坏/冲突备份不改原账本 |
| 数据处理 | 确认全部语音账单后草稿消失；未确认的保留；导出文件不含录音、密钥、连接口令 |
| 外观 | 小字体/大字体、显示缩放、深色系统模式、键盘出现时内容可滚动且保存区可见；长名称和长金额不遮挡；不同窗口宽度、横屏、折叠态另行实测 |

语音准确率验收建议：先用30–50条自己常用描述，覆盖安静、轻噪声、常用菜名/商户、工资、退款和口误，逐条记录 ASR 文本、金额、类别和人工修正。实际识别质量以这批真机语料为准，单条演示成功不能代表全面准确。
